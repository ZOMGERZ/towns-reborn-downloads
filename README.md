# Towns Reborn downloads

The Towns Reborn app for Windows, one release per version. Get the newest from **Releases** on the right:

- `TownsReborn-Setup-<version>.exe` installs the app, with a Start menu shortcut.
- `TownsReborn-Launcher-<version>.exe` is the same app with nothing to install: run it from any folder.

The app updates itself from here. Each release lists its files' sizes and SHA-256 checksums, and the app checks both
before it installs anything.

Windows may say "Windows protected your PC" the first time, because the app isn't code-signed. Click **More info**,
then **Run anyway**.
